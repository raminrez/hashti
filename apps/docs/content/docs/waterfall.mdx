## Parts

| Part                                                | Purpose                                                       |
| --------------------------------------------------- | ------------------------------------------------------------- |
| `Waterfall`                                         | Owns the spans, selection and expansion; a `treegrid`.        |
| `WaterfallHeaderRow` / `WaterfallColumnHeader`      | The header row and its columns.                               |
| `WaterfallAxis` / `WaterfallTick` / `WaterfallMark` | Round times and moments across the axis.                      |
| `WaterfallRow`                                      | One span; carries `--waterfall-start` and `--waterfall-size`. |
| `WaterfallRowHeader`                                | The span's name; indented by `--waterfall-level`.             |
| `WaterfallIndicator`                                | The arrow that expands a span with children.                  |
| `WaterfallCell`                                     | A column of your own, like a size or status.                  |
| `WaterfallBar`                                      | The span on the time axis.                                    |

Styling lives in `@hashti/styles` under `.hashti-waterfall*` — a bordered panel, hairline row rules, tinted bars placed from the row's geometry variables, and a selected row that deepens its bar.
