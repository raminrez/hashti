---
title: Hashti
description: Framework-agnostic components built on ui-sdk, styled with native CSS.
---

import { Button, Switch } from '@hashti/react'

Hashti is a component library with the behavior written once in `@hashti/core` (framework-free TypeScript on [ui-sdk](https://ui-sdk.dev)), styles in plain CSS (`@hashti/styles`), and per-framework renderers like `@hashti/react`.

```tsx
import { Button } from '@hashti/react'

<Button variant="outline">Outline</Button>
```
