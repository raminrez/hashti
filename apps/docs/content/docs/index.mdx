---
title: Hashti
description: Framework-agnostic components built on ui-sdk, styled with native CSS.
---

import { Button, Switch } from '@hashti/react'

Hashti is a component library where the parts and state come from [`@ui-sdk/react`](https://ui-sdk.dev), the styles are plain CSS (`@hashti/styles`), and React wrappers (`@hashti/react`) add the class contract.

```tsx
import { Button } from '@hashti/react'

<Button variant="outline">Outline</Button>
```
