| Part                        | Purpose                                       |
| --------------------------- | --------------------------------------------- |
| `SegmentedControl`          | The radiogroup well.                          |
| `SegmentedControlIndicator` | The chip that slides behind the checked item. |
| `SegmentedControlItem`      | One exclusive choice.                         |
