## Parts

| Part                | Purpose                                          |
| ------------------- | ------------------------------------------------ |
| `Tree`              | Owns selection and which branches are expanded.  |
| `TreeItem`          | One row; give each a unique `value`.             |
| `TreeItemLabel`     | The row's text and its indicator.                |
| `TreeItemIndicator` | The chevron that expands and collapses a branch. |
| `TreeGroup`         | A branch's children.                             |

Styling lives in `@hashti/styles` under `.hashti-tree*` — indented rows from `--tree-level`, selected rows in the selected tint, and a chevron that turns down when its branch opens.
