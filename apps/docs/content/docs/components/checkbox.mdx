# Checkbox

Checkboxes allow users to select multiple options from a group or toggle a single binary setting. Hashti's `Checkbox` and `CheckboxGroup` components are built on [ui-sdk Checkbox](https://ui-sdk.dev/docs), providing native indeterminate state support, tri-state ARIA semantics, group-level required/read-only handling, and Persian architectural color harmonies.

## Architecture & Visual Form

The Hashti checkbox uses an architectural square glyph with precise corner radius and distinct checked iconography:

```
[Unchecked]          [Checked]            [Indeterminate]
┌───┐                ┌───┐                ┌───┐
│   │                │ ✓ │                │ − │
└───┘                └───┘                └───┘
```

- **Dual Mode (Single or Grouped)**: Use standalone `Checkbox` for agreement disclosures (e.g. Terms of Service), or wrap in `CheckboxGroup` for grouped categorical options.
- **Tri-State Support**: Supports `true`, `false`, and `"indeterminate"` for parent-child selection trees (e.g., selecting all permissions in a role).
- **Comprehensive Group Layouts**: `CheckboxGroup` includes built-in accessible labeling, helper descriptions, error messages, and optional/required badges.

## Usage Examples

### Standalone Checkbox

A standalone checkbox is commonly used for terms acceptance or opting into optional settings:

```tsx
import { useState } from "react";
import { Checkbox } from "@hashti/react";

export function SingleCheckboxDemo() {
  const [agreed, setAgreed] = useState(false);

  return (
    <Checkbox checked={agreed} onCheckedChange={(next) => setAgreed(next === true)}>
      I agree to the Hashti Architectural Service Terms and Privacy Policy
    </Checkbox>
  );
}
```

### Indeterminate State (Parent-Child Hierarchy)

When a parent checkbox governs a set of child checkboxes where only some are selected, pass `checked="indeterminate"`. The component renders an architectural minus icon (`−`) and announces `aria-checked="mixed"`:

```tsx
import { useState } from "react";
import { Checkbox } from "@hashti/react";

export function IndeterminateCheckboxDemo() {
  const [selectedItems, setSelectedItems] = useState<string[]>(["read"]);

  const allItems = ["read", "write", "admin"];
  const isAllSelected = selectedItems.length === allItems.length;
  const mixed = selectedItems.length > 0 && !isAllSelected;

  const toggleAll = () => {
    if (isAllSelected) {
      setSelectedItems([]);
    } else {
      setSelectedItems(allItems);
    }
  };

  const toggleItem = (item: string) => {
    setSelectedItems((prev) =>
      prev.includes(item) ? prev.filter((i) => i !== item) : [...prev, item],
    );
  };

  return (
    <div className="flex flex-col gap-2">
      <Checkbox checked={isAllSelected ? true : mixed ? "indeterminate" : false} onCheckedChange={toggleAll}>
        Select All Permissions
      </Checkbox>

      <div className="ml-6 flex flex-col gap-2 border-l border-neutral-200 pl-4 dark:border-neutral-800">
        <Checkbox checked={selectedItems.includes("read")} onCheckedChange={() => toggleItem("read")}>
          Read telemetry logs
        </Checkbox>
        <Checkbox checked={selectedItems.includes("write")} onCheckedChange={() => toggleItem("write")}>
          Write configuration changes
        </Checkbox>
        <Checkbox checked={selectedItems.includes("admin")} onCheckedChange={() => toggleItem("admin")}>
          Administer security tokens
        </Checkbox>
      </div>
    </div>
  );
}
```

### CheckboxGroup with Validation & Description

Group multiple related checkboxes under a single accessible fieldset using `CheckboxGroup`. It coordinates label associations, descriptive helper text, and error states:

```tsx
import { useState } from "react";
import { CheckboxGroup, Checkbox } from "@hashti/react";

export function CheckboxGroupDemo() {
  const [notifications, setNotifications] = useState<string[]>(["security"]);

  return (
    <CheckboxGroup
      label="Notification Preferences"
      description="Choose which event digests you wish to receive via email."
      value={notifications}
      onValueChange={setNotifications}
    >
      <Checkbox value="security">Security incidents and alerts</Checkbox>
      <Checkbox value="deployments">Pipeline deployment completions</Checkbox>
      <Checkbox value="billing">Monthly invoice digests</Checkbox>
      <Checkbox value="newsletter">Hashti architectural community updates</Checkbox>
    </CheckboxGroup>
  );
}
```

### Invalid Validation Error State

When validation fails (such as submitting an empty mandatory group), surface an error through the group's `status`:

```tsx
import { useState } from "react";
import { CheckboxGroup, Checkbox } from "@hashti/react";

export function InvalidCheckboxGroupDemo() {
  const [selected, setSelected] = useState<string[]>([]);
  const isInvalid = selected.length === 0;

  return (
    <CheckboxGroup
      label="Required Compliance Attestation"
      description="You must select at least one compliance standard before provisioning."
      status={isInvalid ? { type: "error", message: "Please select at least one standard." } : undefined}
      value={selected}
      onValueChange={setSelected}
    >
      <Checkbox value="soc2">SOC 2 Type II</Checkbox>
      <Checkbox value="iso27001">ISO / IEC 27001</Checkbox>
      <Checkbox value="hipaa">HIPAA Compliance</Checkbox>
    </CheckboxGroup>
  );
}
```

## Props Reference

### Checkbox Props

`Checkbox` wraps the ui-sdk `Checkbox` from `@ui-sdk/react/checkbox` and accepts its props.

| Prop              | Type                                                             | Default     | Description                                                            |
| :---------------- | :--------------------------------------------------------------- | :---------- | :--------------------------------------------------------------------- |
| `checked`         | `boolean \| "indeterminate"`                                     | —           | Controlled checked state; `"indeterminate"` is the mixed state.        |
| `defaultChecked`  | `boolean \| "indeterminate"`                                     | `false`     | Initial checked state (uncontrolled).                                  |
| `onCheckedChange` | `(checked: boolean \| "indeterminate", details) => void`         | —           | Handler invoked when the checked state changes.                        |
| `disabled`        | `boolean`                                                        | `false`     | Whether the checkbox cannot be interacted with.                        |
| `readOnly`        | `boolean`                                                        | `false`     | Prevents changes while staying focusable and submitted.                |
| `required`        | `boolean`                                                        | `false`     | Blocks form submission until the checkbox is checked.                  |
| `parent`          | `boolean`                                                        | `false`     | Makes it the parent of its group, reflecting and driving all members.  |
| `size`            | `'sm' \| 'md' \| 'lg'`                                           | —           | Control size, applied as `data-size`.                                  |
| `color`           | `'primary' \| 'secondary' \| 'success' \| 'warning' \| 'danger'` | `'primary'` | Semantic color token for the checked surface.                          |
| `value`           | `string`                                                         | —           | Value associated with the checkbox when used inside a `CheckboxGroup`. |
| `children`        | `ReactNode`                                                      | —           | Text label or content rendered adjacent to the checkbox box.           |
| `className`       | `string`                                                         | —           | Additional CSS class names.                                            |

### CheckboxGroup Props

`CheckboxGroup` wraps the ui-sdk `CheckboxGroup` from `@ui-sdk/react/checkbox` and adds Hashti's field anatomy.

| Prop           | Type                        | Default     | Description                                               |
| :------------- | :-------------------------- | :---------- | :-------------------------------------------------------- |
| `label`        | `ReactNode`                 | —           | Accessible label for the group of checkboxes.             |
| `description`  | `ReactNode`                 | —           | Descriptive helper text displayed underneath the label.   |
| `errorMessage` | `ReactNode`                     | —           | Error text shown while the field is invalid.              |
| `value`        | `string[]`                      | —           | Controlled array of selected checkbox values.             |
| `defaultValue` | `string[]`                      | —           | Initial array of selected checkbox values (uncontrolled). |
| `onValueChange`| `(value: string[], details) => void` | —      | Callback invoked when the group selection changes.        |
| `status`       | `FieldStatus`                   | —           | Detached group recovery: warning/error/success message.   |
| `disabled`     | `boolean`                       | `false`     | Disables all child checkboxes within the group.           |
| `required`     | `boolean`                       | `false`     | Blocks submission until at least one member is checked.   |
| `readOnly`     | `boolean`                       | `false`     | Keeps members focusable and submitted, stops changes.     |
| `isOptional`
| `isOptional`   | `boolean`                   | `false`     | Renders an optional badge next to the group label.        |
| `color`        | `SelectionColor`            | `'primary'` | Inherited color accent applied to child checkboxes.       |

## Accessibility & Keyboard Interaction

Hashti checkboxes adhere strictly to the [W3C WAI-ARIA Checkbox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/):

### Keyboard Interaction

- <kbd>Space</kbd>: Toggles the focused checkbox between checked and unchecked (or clears
  indeterminate state).
- <kbd>Tab</kbd>: Moves keyboard focus sequentially through each individual checkbox control.

### ARIA Semantics

- **Indeterminate State**: Sets `aria-checked="mixed"`, signalling to screen readers that a partial subset of child items is active.
- **Group Association**: `CheckboxGroup` renders a semantic `<div role="group">`; inside Hashti's field anatomy the ui-sdk Field wires its label via `aria-labelledby` and its description/error via `aria-describedby`.
- **Validation Signals**: While invalid, the group applies `aria-invalid="true"` and `data-invalid`.
- **High Contrast Focus**: Features an outer offset focus ring meeting the WCAG 2.2 AAA minimum 3:1 contrast ratio against both light and dark canvas surfaces.

| `[data-indeterminate]` | Checkbox, CheckboxIndicator | Present while in the mixed state.               |

| `[data-required]`      | Checkbox, group             | Present when required.                          |
| `[data-invalid]`       | Checkbox, group             | Present while the surrounding field is invalid. |
