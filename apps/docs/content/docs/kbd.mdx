## Props

| Prop       | Type                 | Description                                                    |
| ---------- | -------------------- | -------------------------------------------------------------- |
| `keys`     | `string \| string[]` | Key names, platform-formatted (⌘/⇧/⌃… on Mac, text elsewhere). |
| `children` | `ReactNode`          | Raw content instead of formatted keys.                         |

Adjacent Kbd elements separate themselves; pass `keys` for combos.
