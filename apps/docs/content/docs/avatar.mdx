## Group

<AvatarGroupDemo client:load />

`AvatarGroup` stacks avatars with a 25% overlap and a "+N" count chip when `max` is set. `getInitials(name)` derives fallback initials; Hashti's `Avatar` takes no `name` prop, so pass the initials to `AvatarFallback` yourself. `overflowRenderer(count)` replaces the default chip.

## Props

| Prop    | Type                                   | Description                                        |
| ------- | -------------------------------------- | -------------------------------------------------- |
| `size`  | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | Root size. Default `md`.                           |
| `delay` | `number`                               | On `AvatarFallback`: ms to wait before showing it. |

Styling lives in `@hashti/styles` under `.hashti-avatar`, keyed off `data-size`, fully round, with initials at 40% of the avatar size.
